# App privacy policies

Public privacy policies for these Android apps, published with GitHub Pages so Google Play can link to them:

| App | Policy |
| --- | --- |
| KeyCourier | https://sexualmoose.github.io/app-privacy/keycourier/ |
| PriceLens | https://sexualmoose.github.io/app-privacy/pricelens/ |
| OpenCube | https://sexualmoose.github.io/app-privacy/opencube/ |
| WallPlanner | https://sexualmoose.github.io/app-privacy/wallplanner/ |
| Projector+ | https://sexualmoose.github.io/app-privacy/projectorplus/ |

This repository holds only these policy pages. The apps' source code lives elsewhere and is not public.

Each policy's source of truth is the `PRIVACY.md` file in that app's own repository. When a policy changes,
update it there first, then copy it here (`<app>/index.md`) and change its "Last updated" date.

Questions or requests about a policy: [open an issue](https://github.com/SexualMoose/app-privacy/issues).
